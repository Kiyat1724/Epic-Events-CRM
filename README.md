# Epic Events CRM

Application CRM sécurisée en ligne de commande développée avec Python,
SQLAlchemy et une base de données relationnelle.

## Objectif

L'application permet aux équipes de gestion, commerciales et support
d'Epic Events de gérer les collaborateurs, les clients, les contrats
et les événements selon leurs permissions.

## Architecture

Le projet utilise une architecture en couches :

- interface en ligne de commande ;
- services métier ;
- repositories ;
- modèles SQLAlchemy ;
- base de données relationnelle.

## État du projet

Projet en cours de développement.
